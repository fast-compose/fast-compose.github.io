What is Jetpack Compose?

Jetpack Compose is the modern way to build user interfaces for Android, written in Kotlin. With Compose Multiplatform, the same code also runs on iOS, desktop and the web.

You describe the UI with composable functions, and Compose draws it. When your data changes, Compose updates the screen for you.

How the examples work

The examples are real Jetpack Compose code, run in your browser by compose-script. It's built on Fast Compose, an interpreter that runs Compose code without a compiler or a build.

The first example takes a few seconds to load (about 5 MB, once). The examples need a recent Chrome, Edge, Firefox or Safari.

To write Compose in your own project, use Android Studio, and add the Fast Compose Preview plugin to see your previews as you type.
