Button and State

A UI has to react when the user taps something. In Compose, you keep the changing values in state, and the screen updates whenever the state changes.

State: a counter

To show how many times the button was clicked, keep the count in state:

Click the button above. Here's what happens:

  • mutableStateOf(0) creates a value that Compose watches, starting at 0.
  • remember keeps it when the UI is drawn again. Without it, the count would reset to 0 every time.
  • by lets you use count like a normal variable.
  • count++ changes the state, so Compose runs the code again and shows the new number. This is called recomposition.

State: a toggle

State can hold any value. Here a Boolean switches between two looks:

The icon, its color and the text all read liked, so one click updates all three.

The rule of state: don't change the UI directly. Change the state, and let Compose redraw the UI from it.

Summary

  • Button(onClick = { … }) runs code on click.
  • var x by remember { mutableStateOf(…) } keeps a value that can change.
  • Changing state updates every part of the UI that reads it.
